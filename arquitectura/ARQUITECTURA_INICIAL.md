# Documentación de Arquitectura Inicial

## 1. Visión General
El proyecto **Marketplace** está estructurado bajo una arquitectura web moderna orientada a componentes, ligera y escalable.

## 2. Diagrama de Arquitectura
![Diagrama de Arquitectura Inicial](./imagenes/arquitectura-inicial.png)

## 3. Capas y Componentes
- **Capa de Presentación (Frontend)**: Desarrollada en **Angular CLI**, encargada de la interfaz de usuario dinámicas (SPA).
- **Capa de Estructura Base (Boilerplate)**: Núcleo reestructurado en `boilerplate-main` que contiene los módulos, configuraciones globales y paquetes (`package.json`).
- **Capa de Control de Versiones**: Gestión de código e integración continua respaldada en Git / GitHub.

## 4. Flujo de Datos Inicial
1. El cliente accede a la SPA Angular a través del puerto de desarrollo local (`http://localhost:4200/`).
2. La aplicación gestiona los componentes y vistas renderizadas en el cliente sin recarga del servidor.
3. Preparado para conectarse a microservicios/APIs REST en iteraciones futuras.
